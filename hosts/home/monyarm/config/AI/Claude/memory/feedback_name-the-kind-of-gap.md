When reporting a title as a "gap", say which gap it is: not owned / not modelled in the repo / not extractable.

**Why:** on 2026-11-16, calling Dungeons & Dragons: Chronicles of Mystara the "one real gap" conflated three very different things — the user owned it and it plays fine via Proton; only repo coverage was missing. The user had to stop and ask "isn't that a Steam game?".

**How to apply:** for library/emulation surveys, name the gap explicitly (e.g. "owned and playable, but no module in the repo" or "owned, extraction unverified") rather than a bare "gap", and don't place an unverified extraction candidate in the same bucket as a confirmed dead end.

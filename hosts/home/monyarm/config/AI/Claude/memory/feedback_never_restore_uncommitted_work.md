## name: never-restore-uncommitted-work description: Preserve uncommitted user changes; never use Git restore/reset/checkout as a recovery shortcut. metadata: node_type: memory type: feedback

Never run `git restore`, `git checkout`, or `git reset` on uncommitted work to undo an agent mistake. The index is not a backup: restoring from it can discard unstaged user changes, while restoring from `HEAD` can discard staged and unstaged changes. Do not edit autogenerated files such as `sources.nix` directly.

If an agent edit must be undone, stop first, inspect the exact diff, and use a narrow inverse patch that changes only the agent's own lines. If recovery is uncertain, ask the user rather than guessing.
